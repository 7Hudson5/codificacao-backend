# 🚀 Codificação Backend

Repositório dedicado ao estudo e à prática de desenvolvimento backend, reunindo exemplos de código, exercícios e experimentos relacionados ao ecossistema JavaScript e à construção de aplicações no lado do servidor.

O objetivo é consolidar conhecimentos, explorar tecnologias e registrar a evolução dos estudos em desenvolvimento de software.

## 🛠️ Tecnologias e conceitos

- **Node.js:** execução de JavaScript no lado do servidor.
- **npm:** gerenciamento de pacotes e dependências.
- **CommonJS e ES Modules:** organização e reutilização de código.
- **Streams e Buffers:** processamento e manipulação de dados.
- **HTTP:** comunicação entre clientes e servidores.
- **NestJS:** fundamentos de desenvolvimento backend com framework.
- **APIs REST e rotas:** organização de endpoints e tratamento de requisições.
- **Tratamento de exceções:** identificação e gerenciamento de erros.
- **Variáveis de ambiente:** configuração de aplicações.
- **Serverless e Edge Runtime:** conceitos de execução de aplicações em diferentes ambientes.

## 💻 Pré-requisitos

Para acompanhar os exemplos, recomenda-se ter instalado:

- [Node.js](https://nodejs.org/)
- npm, incluído na instalação do Node.js
- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/) ou outro editor de código.

Para verificar as instalações, execute no terminal:

```bash
node -v
npm -v
git --version
```

## 📥 Como clonar o repositório

Clone o projeto para sua máquina:

```bash
git clone https://github.com/7Hudson5/codificacao-backend.git
```

Entre no diretório:

```bash
cd codificacao-backend
```

## ▶️ Como executar os exemplos

Os exemplos estão organizados em diretórios, permitindo estudar cada conteúdo separadamente.

1. Acesse a pasta do exemplo desejado.
2. Verifique se existe um arquivo `package.json`.
3. Caso exista, instale as dependências com `npm install`.
4. Consulte os scripts disponíveis ou as instruções do exemplo para executá-lo.

Os comandos podem variar de acordo com a configuração de cada projeto.
